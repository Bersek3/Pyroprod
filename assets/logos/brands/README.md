# Logos de la franja

SVG de Simple Icons: https://github.com/simple-icons/simple-icons/tree/develop/icons

Se incluyen los diez logos disponibles descargados para la propuesta local. Los archivos LICENSE.md y DISCLAIMER.md conservan sus condiciones de origen.

Para agregar marcas, coloca sus archivos SVG en esta carpeta e incorpora cada imagen en ambos grupos de `.brand-logo-track` en index.html. El segundo grupo es una copia visual, tiene aria-hidden y alt vac?o para evitar repeticiones accesibles. Ambos grupos deben ser id?nticos para que el movimiento no salte.
